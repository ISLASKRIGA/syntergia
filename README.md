# Syntergia — The emergence of connection

Sitio web y plataforma interactiva para **Syntergia**. Diseñada para reflejar la convergencia entre datos, personas e inteligencia artificial con una identidad visual editorial, geométrica y procedimental.

## ✨ Características

- **Marca e Identidad Procedimental**: Generación de curvas Bézier y ribbons SVG interactivos en tiempo real (`main.js`).
- **Diseño Editorial & Moderno**: Tipografía cuidada (Geist, Instrument Serif, Jost), microinteracciones, modo adaptativo y texturas sutiles.
- **Interacciones Fluidas**: Navegación flotante, menú móvil accesible, efectos parallax y canvas interactivo.
- **Estructura Semántica**: HTML5 accesible, CSS modular sin dependencias externas pesadas.

## 📁 Estructura del Proyecto

- `index.html`: Estructura principal del sitio (Manifiesto, Capacidades, Método, Identidad, Contacto).
- `styles.css`: Sistema de diseño, variables de color, tipografía y responsive layout.
- `main.js`: Lógica del símbolo procedimental SVG, interacción de usuario y animaciones.
- `favicon.svg`: Isotipo vectorial de la marca.
